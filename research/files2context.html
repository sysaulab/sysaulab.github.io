Single-File Python Utility

Text files in. Markdown out.

Pick your files. Pick your folders. Get one Markdown block with every file fenced, labelled, and path-annotated — ready to paste into a chatbot, an LLM prompt, or a README. No install, no config, one script.

What is files2context?

files2context is a small GUI tool that compiles a set of text files into a single Markdown-formatted context blob. You add files or folders, it walks them, and it emits one fenced code block per file with the relative path and a language tag. Copy it, paste it, done.

It exists because the hardest part of giving a model context is not the model. It is the forty minutes you spend opening files, copying their contents, typing a filename above each one, and getting the fences wrong anyway.

The core idea: a codebase is not a pile of files. It is one document with headers. Every file becomes a fenced block whose info string is language:relative/path — so the consumer knows both what it is and where it came from.

There are no plugins, no config files, no project database, no background indexing. There is a file list, a text area, and two buttons that matter: copy and save. The constraint is the feature.

Features

Everything the tool does, in the order you will use it.

Input

Files and folders

Add individual files, whole folders recursively, or type a path by hand. Dotfiles and dotfolders are ignored by default.

Output

Fenced Markdown

Each file is wrapped in a code block whose info string carries the relative path and a language hint derived from the extension.

Budget

Token counting

If tiktoken is installed, the status bar shows the token count using the cl100k_base encoding used by GPT‑4 and ChatGPT.

Export

Copy or save

One click copies the whole Markdown block to the clipboard. Another writes it to a .md file of your choosing.

Housekeeping

List management

Remove the selected entries or clear the entire list. The Markdown regenerates automatically as the list changes.

Status

Size and tokens

The status bar reports total byte size and, when available, the token count. If tiktoken is missing, it tells you so instead.

Install and run

Requires Python 3.6+ with Tkinter, which ships with standard Python distributions. There is nothing to install.

Step Command
Clone git clone https://github.com/sysaulab/files2context
Enter cd files2context
Run python files2context.py

Dependencies

  • Python 3.6+ with Tkinter. Usually included with standard distributions.
  • Optional: tiktoken — install it to display token counts.
pip install tiktoken

Graceful degradation: without tiktoken the tool works exactly as before. The status bar simply shows a reminder in place of the token count. Nothing else changes.

Usage

Two modes. Launch with no arguments for the window, or pass paths and let them load themselves.

GUI mode

Run the script bare and the main window offers the following controls.

Control Action
Add Files Select one or more files via a file dialog.
Add Folder Pick a folder; every file inside is added recursively, excluding hidden entries.
Add path Type or paste a filesystem path and click Add.
Remove Selected Delete the highlighted entries from the list.
Clear All Remove every file from the list.
Copy to Clipboard Copy the entire generated Markdown.
Save as .md Write the content to a .md file.

Command-line arguments

Pass file or folder paths directly when starting the script. They are added automatically after a short delay. 

python files2context.py /path/to/file.txt /path/to/folder

The generated Markdown updates automatically as you modify the file list. There is no generate button, because there is nothing to wait for.

How it works

Four steps, in order. Each one is small enough to read in the source in a sitting.

The steps

  1. File collection. The tool gathers every specified path, expanding folders recursively while ignoring entries that start with a dot.
  2. Common base path. It computes the longest common prefix of all selected files, so the paths in the output are relative rather than absolute.
  3. Markdown generation. Each file becomes a fenced code block with a language identifier derived from the extension and a path relative to the common base, using forward slashes on every platform.
  4. Token estimation. If tiktoken is available, the whole Markdown text is encoded with cl100k_base and the count appears in the status bar beside the byte size.

Why the common prefix matters. Without it, every block would carry a full absolute path and half your token budget would be spent telling the model about /home/you/projects/. With it, the paths are short, portable, and identical across machines.

Example

Suppose you have a project with two files. 

my_project/
├── src/
│   └── main.py
└── README.md

After adding the folder my_project, the generated Markdown looks like this. 

```python:src/main.py
# Content of main.py
```

```markdown:README.md
# Content of README.md
```

The language tag comes first, the relative path second, separated by a colon. Paste the whole thing into a chatbot and it has the full context of the project in one block.

The paths are relative to the common base folder, not to your home directory. Move the project, move the output — it still reads the same.
